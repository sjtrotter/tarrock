## How the run worked (keep doing this)

Every round: an Opus builder from a brief that carried the decisions → a **fresh Opus
critic** briefed to be harsh, that reads the diff against the owning canon docs and
**mutation-tests** the round (deletes guards, inverts rules, hand-edits generated data — a
mutation that leaves the suite green is a finding) → a fix builder → the lead validates
against canon → a scoped commit → STATUS pushed. **Every critic found at least one real
blocking defect the builder's own tests had missed** (a runner that swallowed script
errors; a live-service reset path; a dropped Querent line; uncompensated slow-mo; a
staggered Page that attacked; an untested rim adjacency; a sell verb the doc never
grants; a rebind that amputated the gamepad). Keep the loop for content rounds too.

## Harness facts every future builder should know

`--check-only` doesn't know autoloads (scenes reach `Services` by path with a typed cast;
node components accept injection); a new `class_name` is invisible until `--import`; JSON
numbers come back as floats and `Dictionary ==` is type-strict; timing tests against the
wall clock are flaky headless — drive deltas; a `SceneTree` test that names `SaveModel`
leaks at exit (use `Services.save_game`); RefCounted back-references through the
save/regions/economy graph must be weak; `Area2D.monitoring` cannot be toggled inside a
physics signal; GDScript lambdas capture by value; a `seed()` method collides with the
global; an untyped `[]` ternary branch cannot land in a typed array. All in `godot/tests/README.md`.
